## Backend Live Scoring Confirmation
The backend (`backend/src/services/mlClient.service.ts`) makes **live HTTP POST requests** to `{ML_SERVICE_URL}/predict` for every incoming reading, with a 2500 ms timeout and one automatic retry. If ml-service is unreachable, the reading is stored as **unscored** (mlScore: null) without crashing the ingestion pipeline.

## Methodology
- **Point-Level Evaluation**: Strict timestamp-by-timestamp classification accuracy.
- **Event-Level Evaluation**: Segment-based detection. A sensor fault or weather event spanning several 10-minute intervals is considered successfully caught if alerted during its duration.
- **Sanity Check**: Always-normal baseline scores 0.0 recall, validating the evaluation harness.
- **LSTM Training**: 4 epochs, batch size 64, CPU-only training (~20–24 seconds per dataset).
